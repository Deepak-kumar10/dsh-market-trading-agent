================================================================================
                    WHAT THE AGENT DOES TODAY
================================================================================

The production-ready agent performs:

1. Index Analysis (NIFTY/BANKNIFTY):
   - Current prices from WebSocket feeds
   - Trend direction detection (UPTREND/DOWNTREND/NEUTRAL)
   - Trend strength assessment

2. Stock-Level Screening (Top 4 Indian Stocks):
   - Tata Steel (STEL) - Infrastructure/Steel
   - Reliance Industries (RIL) - Oil & Consumables
   - HDFC Bank (HDBANK) - Banking (~0.5416 of NIFTY)
   - ICICI Bank (ICICIBANK) - Banking (~0.9368 of NIFTY)

3. Technical Indicator Analysis:
   - RSI (Relative Strength Index): Overbought (>70), Oversold (<30)
   - MACD (Moving Average Convergence Divergence): Momentum signals
   - Moving Averages: EMA alignment for trend direction

4. Trade Opportunity Generation:
   - BUY positions prioritized by profit potential
   - SELL/REMOVE from technical pullbacks
   - Scoring algorithm with risk-adjusted estimates

5. Risk Management Defaults:
   - 30% maximum position size per day
   - Stop-loss: 5% below entry price
   - Take-profit: +8%, then +15% targets
   - Cash buffer: 20% minimum reserve

================================================================================
                    API CREDENTIALS FOR PRODUCTION
================================================================================

For production use, connect to actual NSE/BSE markets:

1. Add credentials to .env file:

   ```
   NSE_API_KEY=your_actual_api_key_here
   NSE_API_SECRET=your_actual_secret_here
   ```

2. Alternatively set environment variables before running:
   
   ```powershell
   setx NSE_API_KEY "your_api_key"
   setx NSE_API_SECRET "your_secret"
   ```

3. Run demo with actual credentials (script reads from .env):
   
   ```
   python MARKET_API_INTEGRATION.py
   ```
